# Guess the Number

Using Python, I created a simple number guessing game that asks the user to guess a randomly chosen two-digit number.

- The program selects a random number between 10 and 99
- The user enters a guess
- The program tells the user whether their guess is too high, too low, or correct

``` example
Welcome to the Guess the number Game. to win, you must guess the two digit number that I am thinking of.
Guess the number: 42
Too low. Try again. 73
Game over.
```

Methods used:

1. Variables
2. Input
3. Type conversion
4. Conditional statements
5. Random number generation
6. Print
