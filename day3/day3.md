# Haunted House Escape

Using Python, I created a simple text adventure program that asks the user to choose a direction and a route.

- The user chooses left or right
- If they choose right, they then choose between the basement and attic
- If they choose the attic, they learn the correct door that contains the key
- The program responds with a success or failure message based on the choice

``` example
Welcome to the Haunted House. To escape, you must find the hidden key!
Which direction do you want to enter? Left press L or right press R: R
Which route do you want to enter? Basement press B or Attic press A: A
There is information for you: there are three doors. One leads to the kitchen, one to the bedroom, and one to the washroom. The key is in the kitchen.
Which door do you want to open? Door 1 press D1, door 2 press D2, or door 3 press D3: D2
Wrong door. You are haunted.
Game over.
```

Methods used:

1. Variables
2. Input
3. Conditional statements
4. Print
