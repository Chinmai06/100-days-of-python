# Loan Calculator

Using Python, I created a simple loan calculator program that asks the user for:

- The loan amount
- The annual interest rate (without the percentage sign)
- The number of years to pay off the loan

Then it calculates monthly EMI, total amount repayable, and total interest payable.

``` example
Welcome to the Loan Calculator!
Enter the Loan Amount: 500000
Enter your Interest Rate:(Dont include the percentage sign) 15
Enter the no of years you want to pay off the loan: 12
Monthly EMI IS:  7504.38
Total Amount Repayable IS:  1080631.27
Total Interest Payable IS:  580631.27
```

Methods used:

1. Variables
2. Input
3. Type conversion
4. Arithmetic operations
5. Print
