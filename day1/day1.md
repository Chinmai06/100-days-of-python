# Sports Team Name generator

Using Python, I created a simple program that generates a sports team name by asking the user for:

- The city they were born in

- A local animal

Then it combines them to create a team name.

``` example

Enter, What city did you grow up in?
Milan 
Enter, What is your local animal?
Bisciones
Your team name could be: Milan Bisciones
```

Methods used:

1. Variables
2. Input
3. String concatenation
4. Print
